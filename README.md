# «Мой день» — Telegram-бот напоминаний

## Что умеет
- **Голосовые задачи**: продиктуйте голосовое — бот сам переведёт в текст и поставит напоминание
- **Умный парсер**: «купить молоко завтра в 10», «позвонить в среду в шесть вечера»,
  «выпить воды» (время не назвали — через 30 минут; день не назвали — сегодня)
- **Напоминания с кнопками**: ✅ Сделал / ⏰ +15 мин / ⏰ +1 час; повторяет, пока не подтвердите
- **Голосовые ответы** бота (gTTS)
- **Семейный доступ**: /code выдаёт 4-значный код на 10 минут, /link 1234 подключает родного —
  он может ставить задачи текстом и каждый день в 21:00 получает отчёт
- **/report** — отчёт за день, **/repeat N** — интервал повтора, **/tasks** — список

## Запуск на компьютере / VPS
```bash
pip install -r requirements.txt
sudo apt install ffmpeg        # нужен для распознавания голосовых
export BOT_TOKEN=токен_от_BotFather
python bot.py
```

## Запуск на старом Android (бесплатно, Termux)
```bash
pkg install python ffmpeg
pip install -r requirements.txt
export BOT_TOKEN=токен
python bot.py
```
Держать телефон на зарядке. Для 24/7 лучше любой VPS за ~150–300 ₽/мес
или бесплатные tier-ы: Oracle Cloud Always Free, fly.io, Replit.

## Как получить токен
1. В Telegram найдите @BotFather
2. /newbot → придумайте имя и username
3. Скопируйте токен, вставьте в BOT_TOKEN
